\section{Python Fundamentals}
\subsection{Comments and Output}

We can use the \mintinline{python}{print()} function to display text or output values. Text must be inside quotes, 
otherwise Python will return a syntax error.

\begin{example}
    \
\begin{minted}{python} 
    print("Hello world!") 
    print("I love Praxis!") # Automatically prints on a new line
\end{minted} 
    \textit{Output.}
\begin{minted}{text}
    Hello world!
    I love Praxis!
\end{minted}
\end{example}

Any text after \mintinline{python}{#} is a comment. These will not be read by Python, and are used to make code
more readable. You can also do math inside of a print statement. Observe the absence of quotes.

\begin{example}
    \
\begin{minted}{python}
    print("What is 3 + 10?") 
    print("3 + 10 =", 3 + 10) # Prints 13, as 3 + 10 = 13
\end{minted}
    \textit{Output.}
\begin{minted}{text}
    What is 3 + 10?
    3 + 10 = 13
\end{minted}
\end{example}

\subsubsection{Interlude (Local and Global Variables)}

Variables that are created outside of a function are known as global variables. Global variables can be used by 
everyone, both inside of functions and outside. Variables that are created inside a function are known as local 
variables. Local variables can only be used inside their functions. 

We can however create global variables inside a function by using the \mintinline{python}{global} keyword.

\subsection{Conditional Statements}

The \mintinline{python}{if} statement evaluates an expression to determine its boolean value. If 
\mintinline{python}{True}, the code block inside the statement is executed. If \mintinline{python}{False}, the 
code block is skipped.

\begin{example}
    \
\begin{minted}{python}
    if grade >= 85:
        print("GPV: 4.0")
    elif grade >= 80: # Python will move on to this if the original is False
        print("GPV: 3.7")
    elif grade >= 77: # Same for this, if both of the above are False
        print("GPV: 3.3")
    else: # Code block will be executed if all of the above are False
        print("Is this Praxis?")
\end{minted}
\end{example}

Notice that in Python, indentation is used to determine which statements belong together. \\[-0.5em]

If we have a lot of cases, we may wish to use a \mintinline{python}{match} statement instead.

\begin{example}
    \
\begin{minted}{python}
    match color:
        case "red":
            print("Roses are red.")
        case "yellow" | "green": # We can check for more than one value match
            print("Grass is green, yellow if dead.")
        case "blue": if time == "day" # We can add an extra condition check
            print("The sky is blue.")
        case _: # This will execute if there are no matches
            print("This color is boring.")
\end{minted}
\end{example}

\subsection{Loops}

A \mintinline{python}{for} loop is used for iterating over a sequence (a list, a tuple, a set, or a string).
Most commonly, we use the \mintinline{python}{range} data type, which represents an immutable sequence of 
numbers.

\begin{example}
    \
\begin{minted}{python}
    for i in range(3): # Notice how by default, we begin at 0
        print("I am", i)

    print(" ")

    for i in range(3, 10, 3): # Syntax is (start, stop, step)
        print("I am", i)
\end{minted}
    \textit{Output.}
\begin{minted}{text}
    I am 0
    I am 1
    I am 2
     
    I am 3
    I am 6
    I am 9
\end{minted}
\end{example}

A \mintinline{python}{while} loop will execute a set of statements as long as a condition is 
\mintinline{python}{True}. If the condition is always \mintinline{python}{True}, we could end up in an 
infinite loop. 

\begin{example}
    \
\begin{minted}{python}
    height = 1
    while True: # This loop will continue forever, unless...
        print("I am", height, "feet tall!")
        height += 1
        if height > 6:
            break # This will exit the loop
\end{minted}
    \textit{Output.}
\begin{minted}{text}
    I am 1 feet tall!
    I am 2 feet tall!
    I am 3 feet tall!
    I am 4 feet tall!
    I am 5 feet tall!
    I am 6 feet tall!
\end{minted}
\end{example}

Observe the use of \mintinline{python}{break} above. If we wish to stop the current iteration but stay in the 
loop, we can use \mintinline{python}{continue}. We can also use an \mintinline{python}{else} statement to run 
a block of code when the condition is no longer \mintinline{python}{True}. This means that exiting the loop 
using \mintinline{python}{break} will not run the code inside the \mintinline{python}{else} statement.

\subsection{Functions}

A function is defined using the \mintinline{python}{def} keyword. To call a function, write its name followed by 
parentheses.

\begin{example}
    \
\begin{minted}{python}
    def print_hello():
        print("Hello there!")
    
    print_hello()
\end{minted}
    \textit{Output.}
\begin{minted}{text}
    Hello there!
\end{minted}
\end{example}

Functions can send data back to the code that called them using the \mintinline{python}{return} statement. When 
a function reaches a \mintinline{python}{return} statement, it stops executing and sends the result back. If a 
function doesn't have a \mintinline{python}{return} statement, it returns \mintinline{python}{None} by default. \\[-0.5em]

We can also pass information into functions as arguments. These are specified after the function name, inside the 
parentheses. You can also assign default values to parameters.

\begin{example}
    \
\begin{minted}{python}
    def greeting_message(name1, name2 = "alien"): # name2 has a default value
        return "Hi " + name1 + ", hello " + name2 + "!"
    
    greeting_message("cat", "dog") # Nothing is printed (why?)
    print(greeting_message("cow")) # Here we exclude a second argument
\end{minted}
    \textit{Output.}
\begin{minted}{text}
    Hi cow, hello alien!
\end{minted}
\end{example}

If you do not know how many arguments will be passed into your function, add a \mintinline{python}{*} before the 
parameter name to send a tuple of arguments. You can also add a \mintinline{python}{**} before the parameter name 
to send the function a dictionary of arguments.

\subsection{User Input}
You can use \mintinline{python}{input()} to ask the user for input. You can include a prompt inside the parentheses, which 
is a message that will display before the user input on the same line. The input from the user is always 
treated as a string.

\subsection{Lists and Tuples}

Lists and tuples are used to store multiple items in a single variable. Lists are mutable and use square brackets, 
whereas tuples are immutable and use parentheses. Items in lists and tuples are ordered and allow duplicate values. \\[-0.5em]

Items are also indexed, the first item has index \mintinline{python}{[0]}, the second item has index \mintinline{python}{[1]}, etc. 
Lists and tuples can contain different data types. To determine how many items a tuple or list has, use the 
\mintinline{python}{len()} function. You can check if an item is present in a list or tuple using the \mintinline{python}{in} 
keyword. \\[-0.5em]

To insert a new list item without replacing any of the existing values, we can use the \mintinline{python}{insert()} method. To 
add an item to the end of the list, use the \mintinline{python}{append()} method. To append items from another list to the current 
list, use the \mintinline{python}{extend()} method. To remove a item, use the \mintinline{python}{remove()} method. If there is more 
than one item with the specified value, the \mintinline{python}{remove()} method removes the first occurrence. The \mintinline{python}{pop()} 
method removes the specified index. If you do not specify the index, the \mintinline{python}{pop()} method removes the last item. \\[-0.5em]

List objects have a \mintinline{python}{sort()} method that will sort the list alphanumerically, ascending, by default. To sort descending, 
use the keyword argument \mintinline{python}{reverse = True}. The \mintinline{python}{reverse()} method reverses the current sorting order of the 
elements. To copy a list, you can use the \mintinline{python}{copy()} method. \\[-0.5em]

For lists and tuples, you can use the \mintinline{python}{count()} method to return the number of elements with the specified value. You 
can also use the \mintinline{python}{index()} method to return the position of where a specified value is found.

\subsection{Dictionaries}

Dictionaries are used to score data values in key:value pairs. They are unordered (in Python 3.3), mutable, and use curly brackets. Similarly 
to lists and tuples, you can use the \mintinline{python}{len()} function to see how many items a dictionary has. \\[-0.5em]

You can access an item of a dictionary by referring to its key name inside square brackets. There is also a method called \mintinline{python}{get()} 
that will give you the same result. The \mintinline{python}{keys()} method will return a list of all the keys in the dictionary. The 
\mintinline{python}{values()} method will return a list of all the values in the dictionary. The \mintinline{python}{items}. method will return 
each item in a dictionary, as tuples in a list. To determine if a specified key is present in a dictionary use the \mintinline{python}{in} keyword. \\[-0.5em]

Adding an item to a dictionary is done by using a new index key and assigning a value to it. The \mintinline{python}{update()} method will update the 
dictionary with the items from a given argument. If the item does not exist, the item will be added. The \mintinline{python}{pop()} method removes the item 
with the specified key name. To copy a dictionary, you can use the \mintinline{python}{copy()} method.
